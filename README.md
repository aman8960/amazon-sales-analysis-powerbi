
# Amazon Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project presents an interactive **Amazon Sales Analysis Dashboard** created using **Microsoft Power BI**. The dashboard analyzes Amazon sales data to understand sales performance, profitability, customer demand, shipping costs, markets, countries, cities, product categories, and shipping modes.

The main objective of this project is to transform raw sales data into meaningful **business insights and interactive visualizations** that can support data-driven decision-making.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Exploratory Data Analysis (EDA)

## 📈 Dashboard Analysis

The dashboard provides insights into:

- Total Sales
- Total Profit
- Total Quantity Sold
- Shipping Cost
- Sales by Country
- Sales by City
- Sales by Market
- Sales by Product Category
- Sales by Ship Mode
- Country-wise Performance
- Market-wise Performance
- Category-wise Sales Performance

## 🔍 Key Insights

- Identified the highest-performing countries and cities based on sales.
- Compared sales performance across different global markets.
- Analyzed the contribution of different product categories.
- Evaluated sales performance across different shipping modes.
- Analyzed profit and shipping costs to understand overall business performance.
- Used interactive filters for **Category** and **Market** to analyze specific segments.

## 🎯 Project Objective

The goal of this project is to demonstrate practical skills in **Power BI, data analysis, data visualization, and business intelligence** by converting sales data into an interactive dashboard.
